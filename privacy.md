## Who maintains this website

This website is a student project maintained by **Atikul Islam Rabbi**, a student
of the Department of Bengali, Honours Batch 2025–26, at Islamia Government
College, Sirajganj. It is not the official website of the college and it is not
operated by the college administration.

The archive is stored in a public repository on GitHub and published through
GitHub Pages. There is no database and no server behind the site: the pages you
read are static files generated from Markdown documents.

## What is published

- **Memories** written or supplied by members of the batch, with the
  contributor's name only when they have agreed to be named.
- **Event records**: titles, dates, venues and descriptions of programmes, once
  those details are confirmed.
- **Quotations** that are in the public domain with a named source, or short
  reflections contributed with the author's permission.
- **Photographs** with captions and accessible descriptions, published only
  under the consent rules below.
- **Member profiles**, which are entirely optional.

## Photographs and consent

Photographs of identifiable people are treated as personal data.

- A photograph is published only when **everyone identifiable in it** has agreed
  to appear on a public website.
- The contributor must hold the right to share the image. Photographs copied
  from another person's account without permission are not published.
- Captions must describe the image accurately, including the place and the
  occasion where those are known.
- Photographs of minors are not published without the agreement of a parent or
  guardian.
- Images may be cropped or blurred to remove someone who has not agreed, or the
  photograph may be left out entirely.
- Members who prefer not to appear are not identified, and no comment is made
  about their decision.

## Optional member profiles

A profile is published only when the member has confirmed, in writing or
through the batch's agreed channel, that their name, biography and photograph
may appear publicly. Consent can be limited — for example, a name without a
photograph, or a biography without a photograph. A profile without recorded
consent is not displayed anywhere on this website, is not included in search
results and is not listed in the sitemap.

## What is not published

Phone numbers, home addresses, student identification numbers, examination
results, medical information, financial details, private conversations, and any
material about a person who has not agreed to be mentioned. Where such details
are essential to a memory, the memory is not published.

## Corrections and removal requests

If something about you is wrong, or you want it removed:

1. Ask the maintainer through the batch's agreed contact channel, or open an
   issue in the public repository.
2. Describe the page and what should change. A link to the page is the fastest
   way to identify it.
3. The maintainer will correct or remove the content from the repository and
   from the published website as soon as reasonably possible — usually within a
   few days, sooner where the request involves personal safety.

No reason has to be given for a removal request that concerns your own
information, and no discussion of the request will be published.

## Public repository and public hosting

This archive is intentionally public, which has consequences worth understanding
before contributing:

- **The content files are public.** Memories, captions and metadata live in a
  public GitHub repository. Anyone can read, copy or fork them.
- **Git history is public.** Removing a file removes it from the current version
  of the website, but the earlier version may remain visible in the repository
  history, and in copies that others have already made.
- **Search engines and archives.** Once a page has been public, search engines,
  social networks and web archives may have cached or indexed a copy. The
  maintainer can remove the content from this website and can request removal
  from search engines, but **complete removal from the internet cannot be
  promised**.
- **Nothing is private by default.** A publication flag such as
  `published: false` keeps an entry out of the built website; it does not make a
  file that has been committed to a public repository private.

Please keep these points in mind when deciding what to send.

## External services, cookies and tracking

- The public website makes **no third-party requests**. Fonts are self-hosted,
  images and scripts are served from this repository, and there are no embedded
  advertising or analytics scripts.
- The website sets **no cookies** and stores nothing in your browser.
- The search page downloads a JSON index from this repository and searches it in
  your browser. Your query is not sent anywhere; it is only added to the page URL
  so that a result page can be shared or bookmarked.
- The content management panel at `/admin/` is a maintenance tool for the
  maintainer. It is not part of the public website, it is excluded from search
  engines, and it loads the Decap CMS application from a public content delivery
  network when it is opened. Only the maintainer is authorised to use it.
- GitHub, as the host, may process standard technical information such as IP
  addresses in server logs. That processing is governed by GitHub's own privacy
  statement, not by this policy.

## Students and privacy

Most people in this archive are students. Names are published only with
agreement, photographs only with consent, and no academic records, marks or
personal identifiers are published at all.

## Changes to this policy

channel or a submission form is added. The current version is always the one
published on this page, and the repository history shows when it last changed.
